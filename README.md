# architecture-standart

Проектная работа 3-го спринта («Цифровая трансформация банка «Стандарт»»).

| Папка | Что внутри |
|-------|-----------|
| `Task1/` | Карта IT-ландшафта и схема интеграции приложений (draw.io + PNG) |
| `Task2/` | Таблица требований FURPS+ (`FURPS+.md`) |
| `Task3/` | ADR «Открытие депозитов онлайн» (`ADR.md`) и диаграммы C4: контекст и контейнеры |
| `Task4/` | ADR «Передача ставок в кол-центр», диаграммы C4 (контекст и компоненты), список задач `Tasks.md`, RoadMap |
| `docs/` | Пошаговый план работы (`STEPS.md`) и список вопросов (`QUESTIONS.md`) |
| `scripts/` | Скрипты, из которых собираются диаграммы, и команды для Git |

## Как открыть и править диаграммы

Файлы `.drawio` открываются в [draw.io](https://app.diagrams.net): *Файл → Открыть из → Устройство*.
Рядом лежат готовые `.png`, их можно смотреть без редактора.

## Как пересобрать диаграммы

```bash
pip install pillow
python3 scripts/gen_task1.py
python3 scripts/gen_task3.py
python3 scripts/gen_task4.py   # диаграммы C4, RoadMap и Task4/Tasks.md
```

Список задач (`Task4/Tasks.md`) и RoadMap строятся из одних и тех же данных в `scripts/gen_task4.py`,
поэтому номера задач в них всегда совпадают.
