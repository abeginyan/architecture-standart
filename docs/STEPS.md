## Шаг 3. Задание 3 — ADR «Открытие депозитов онлайн»

| | |
|---|---|
| **Требует** | ADR по шаблону: Use Cases, функциональные и нефункциональные требования, решение с диаграммами контекста и контейнеров C4 (детализировать интернет-банк и АБС), альтернативы, недостатки и риски. Диаграммы — отдельными файлами |
| **Результат** | `Task3/ADR.md`, `Task3/C4_Context.*`, `Task3/C4_Container.*` |

**Идея решения**

1. Интернет-банк и сайт не ходят в АБС. Всё идёт через новый **Сервис депозитов** со своей базой.
2. Сервис депозитов общается с АБС **через Kafka** и «Интеграционный адаптер АБС» (с ограничением скорости).
3. Ставки и согласование особых ставок переезжают из Excel в АБС (как намекает задание).
4. СМС-подтверждение делает новый **Сервис уведомлений** (не трогаем ядро подрядчика).
5. Заявки с сайта уходят в систему кол-центра.

**Проверка покрытия.** Каждый Use Case UC1–UC9 помечен на стрелках диаграммы контейнеров, поэтому видно, что диаграмма покрывает все сценарии (это требование задания).

- Решение (см. `QUESTIONS.md`): как интернет-банк сегодня отправляет СМС (я предположил, что через СМС-шлюз).
- Решение (см. `QUESTIONS.md`): кто считает персональные ставки и кто открывает депозит после подтверждения.
- Решение (см. `QUESTIONS.md`): есть ли в банке платформа для контейнеров и опыт с Kafka.

## Шаг 4. Задание 4 — ставки в кол-центр, список задач, RoadMap

| | |
|---|---|
| **Требует** | (1) Новый ADR: Use Cases, требования, диаграммы контекста и компонентов, альтернативы, риски; (2) список крупных задач по каждой системе; (3) RoadMap в draw.io на 6 месяцев MVP + цель на год |
| **Результат** | `Task4/ADR.md`, `Task4/C4_Context.*`, `Task4/C4_Component.*`, `Task4/Tasks.md`, `Task4/RoadMap.*` |

**Идея решения**

- Кол-центр банка получает ставки по REST API Сервиса депозитов (с локальной копией).
- Партнёрский кол-центр получает CSV-файл по SFTP (ежедневно и при изменении ставок). Только общие ставки.
- «На основе текущего процесса работы со ставками»: до готовности модуля в АБС ставки загружаются из того же Excel через временную страницу ручного импорта.
- Решение (см. `QUESTIONS.md`): кто хранит SFTP-сервер и как понимать «текущий процесс».

**RoadMap**

- Дорожки (строки) — системы, блоки — задачи с номерами `T1`…`T31`, по горизонтали M1–M12.
- Красные линии: конец M6 (MVP) и конец M12 (цель).
- Цвета: оранжевый — MVP, зелёный — ставки для кол-центров (Задание 4), синий — цель на год.
- Зависимости между задачами проверены скриптом (ни одна не стартует раньше своей предшественницы), они перечислены в `Tasks.md`.
